# Экспертная система диагностики автомобиля (учебный проект)

## 1. Архитектура проекта
Проект построен по модульной архитектуре и разделен на три слоя:

- **GUI (PySide6)** — отвечает за сбор данных, пошаговый опрос, визуализацию результата.
- **Логика экспертной системы** — реализует правила ЕСЛИ–ТО и механизм вывода.
- **База данных (SQLite)** — хранит справочники, правила, рекомендации и историю диагностики.

## 2. Структура папок
```
/workspace/gpt
├── app
│   ├── db
│   │   └── database.py         # Инициализация SQLite и сохранение истории
│   ├── es
│   │   └── engine.py           # Экспертная система и правила
│   ├── gui
│   │   └── main_window.py      # PySide6 GUI, опрос и вывод диагноза
│   └── data
│       └── diagnostics.db      # Локальная БД (создается при первом запуске)
├── main.py                     # Точка входа
├── requirements.txt            # Зависимости
└── README.md
```

## 3. Схема БД SQLite
База данных создается автоматически при первом запуске.

- **cars** (марка, модель, год)
- **symptoms** (наименование, категория)
- **rules** (условия, диагноз, вероятность)
- **recommendations** (связь с rule_id)
- **history** (история диагностик)

Схема реализована в `app/db/database.py`.

## 4. Запуск приложения
```bash
pip install -r requirements.txt
python main.py
```

Если диагностика не запускается, проверьте:
- Установлен ли PySide6 и доступен ли Qt.
- Заполнены ли обязательные поля (они помечены `*` и подсвечиваются красным при ошибке).
- Выбран ли хотя бы один симптом или условие.
